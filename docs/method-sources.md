# 五种方法视角，怎样用在商业判断上

本项目的“第一性原理”是一个实践方向：质疑决定行动的前提，拆到足以改变判断的事实和机制，再重建选择。商业问题包含人的偏好、组织权限和不确定性，不能像几何证明一样从几条“公理”推出必然盈利。

下面五组来源帮助完成这件事，但并不共同构成一个由原作者发布的“第一性原理商业体系”。把它们组合成 Agent 指令是本项目的设计。

| 方法视角 | 可核实的一手来源 | 本项目如何使用 | 不作的推断 |
|---|---|---|---|
| **机制与反证** | Richard Feynman，1974 年科学诚信演讲：[Caltech 原文](https://calteches.library.caltech.edu/51/2/CargoCult.htm)。强调不自欺、呈现会削弱结论的信息。 | 解释为什么某个方案会产生结果，主动寻找会使推荐失败的观察。 | 这不是费曼为创业设计的固定四步法；科学诚信不等于商业成功保证。 |
| **客户处境与进展** | Clayton Christensen 相关的 [Jobs to Be Done，Christensen Institute](https://www.christenseninstitute.org/theory/jobs-to-be-done/)。关注具体处境中希望取得的进展。 | 找发生时刻、现有替代和切换阻力；区分产品点子与客户真正要完成的事。 | 不把画像、情绪或社会因素一概排除；不声称 JTBD 仅有一位创始人或一种学派。 |
| **价值与成本重构** | W. Chan Kim 与 Renée Mauborgne：[Four Actions Framework，作者官方站](https://www.blueoceanstrategy.com/tools/four-actions-framework/)。 | 质疑行业默认交付项，检查删减与新增怎样同时改变客户价值和经营成本。 | 差异化、少竞争或一张价值曲线不能证明“蓝海”已经成立。 |
| **行为证据** | Rob Fitzpatrick：[The Mom Test，作者书站](https://www.momtestbook.com/)。 | 优先问最近发生过什么、如何解决、付出过什么；分开称赞、承诺和兑现。 | 不能把所有自述都当作事实，也不能把访谈或口头预约等同付款。 |
| **可改判的验证** | Teresa Torres：[Discovering Solutions，Product Talk](https://www.producttalk.org/discovering-solutions/)。区分客户机会、解法与假设测试。 | 选能影响下一笔投入的关键未知，设计小测试，并写清通过、反证及无法判定之后分别怎样行动。 | 一次模型回答不等于持续客户发现；点击或发起结账不等于完成购买。 |

姓名只用于说明思想来源。项目独立开发，与上述作者、其继承人或机构无关联，未获其认可或背书。它由一个 Agent 使用多种方法视角工作，不模拟这些人物本人，不制造名人引语，也不把同一模型的多个意见当成独立证据。

我们不要求每次回答都展示五种方法。对于一个明确的小问题，选一两个能改变决定的检查即可；生活和工作选择也不必强行转成收入最大化。方法的价值取决于是否帮助提出更准确、可验证的判断，不能由人物声望代替检验。
