# 用与不用：实际差别是什么？

2026-11-04 · v1.3.0 · 实验版

**结论：尚未证明稳定优于普通 agent。两道未见题，一道各有优劣，一道平局。** 新版在部分验证设计上更清楚；无技能回答也发现了新版遗漏的可行收入方向。没有真实交易或收入效果验证。

## 最值得看的差别

| 案例 | 不用 skill | 使用 v1.3.0 | 盲评结论 |
|---|---|---|---|
| 羽毛球穿线，是否改做 AI 分析 | 保留已有订单、改善排期、试集中收拍；还从原教练经历发现基础陪练／小课路线。 | 同样保留穿线；进一步区分到店不便、需求少、已有穿线师，检查新增取送是否只是转移老客；提醒未触达队员或没有换线时机不能否定需求。遗漏了独立陪练路线。 | **混合**：基线拓宽了赚钱路径，新版改善了渠道验证，不能宣布整体胜出。 |
| 社区照片整理，究竟谁买什么 | 将居民整理指导和子女付费手机协助分开，提出无需陌生软件的电话／现场服务；相册另收排版费。 | 区分使用者、付款人、场地，明确没接触付款人不算拒购，并给出相册、课程的改判条件。 | **平**：都合理重定义问题、提出可执行交易测试；不同排序没有已知优劣。 |

**具体的局部价值：** 穿线案例中，“没有收到球馆订单”可能意味着教练没触达队员、试期没有换线需要，也可能意味着已有供应方够好。新版要求先区分这些情况，再决定是否改渠道、等待购买时机或停止取送；同时检查取送是否新增了订单。这比只数成交更有诊断性。

**具体的代价：** 新版没有提出经营者原有教练能力可支持的独立陪练收入路线，而无技能回答提出了。这正是机会发现的实质遗漏，不能用验证流程更完整抵消后宣称获胜。

照片案例也暴露了局限：从“愿意现场、不愿远程”不能唯一推断安全顾虑，可能是现场更易解决、时机或信任不同；拒付相册排版费也不能唯一归因为自己会做。这些是候选解释，不是已经识别的原因。

## 怎样做的，以及不能推断什么

- 共三个合成经营案例；C0 为开发比较，含基线、旧版及八个上游，共十份回答。H1/H2 每题各一份基线和新版回答，共四份。没有挑选多次运行中的最好答案。
- 独立案例作者先封存 H1/H2；新版核心及参考文件冻结后才向主线程揭示题目，再分别派发答题。没有按这两题结果修改已经冻结的指令。
- 使用 Codex 同一默认代理模型配置，没有模型覆盖；宿主提供的是 GPT-6 系列身份，未取得精确后端快照与采样参数。因此不能承诺逐字复现或跨模型同效。没有为技能版本配置额外思考预算。
- 答题使用独立子代理上下文，建议不超过 650 个中文字，不联网、不外联、不读其他答卷；建议长度并非硬截断。上游只读取 SKILL 及取得的相关参考，不是完整安装所有依赖。数字分数和流程负担只是本次出现的现象。
- 无技能组明确不加载任务技能正文，但宿主系统规则和可用技能名称/描述可能共享；这是指令层隔离，不是文件系统或运行时强隔离。基础模型本身可能已掌握这些方法。
- H1/H2 回答随机标为 A/B，单个独立评审只看题目与答案，评完才揭盲。H1 A=基线、B=新版；H2 A=新版、B=基线。没有第二位评审一致性验证，没有显著性估计，没有统计胜率。
- 不同路线只要都合理，不因新奇或更多框架名称判胜；判断应改变实际行动。原始答案保留，不将局部细节包装成全面提升。
- 这不是新版相对旧版的未见题直接对照；旧版只出现在 C0。此前版本也没有建立稳定的整体判断优势，这次不借改名重置证据。
- 案例没有真实顾客。交易、价格、身体负担、复购、市场范围都需要现实检验。文件格式验收、离线包校验与模型效果、真实赚钱效果是不同的验收项。

## 应该怎样宣传

可以说：**一个可检查、可携带的决策方法，帮助 agent 追问交易假设并设计下一次验证；提供公开用／不用对照。**

不能说：已经证明比普通 agent 更会赚钱、稳定找到隐藏商机、五位大师替你决策、通过商业有效性认证。

如果你的选择标准是“必须显著胜过已有强模型才值得安装”，本轮尚未达到。若你想复用同一套提问和证据边界、跨聊天工具携带它、检查并改进其判断，这个包提供了具体可用的材料。欢迎用新的脱敏真实案例检验它，尤其提交失败结果。
